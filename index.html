Tool Guide & Keyboard Shortcuts

🧵 Warp & Weft

Warp colors define the borders of the cells. Weft colors are used to paint the inner sections of each cell. Warp colors repeat automatically across the columns.

Select a color from the Warp or Weft panel. Use the color picker to customize each yarn color.

🖌 Paint Tool

Click the Paint Tool to unlock painting automatically. Select a Weft color, then click a section to paint it. Click the same color again to remove it.

🔒 Painting Lock

Painting is locked by default. Click the lock button to toggle painting lock on or off.

✋ Hand Tool & Canvas Navigation

Hold Space and drag with your mouse to move around the canvas. On mobile devices, swipe directly on the canvas to navigate.

📐 Dimensions & Yarn Structure

Columns and Rows define the size of your design grid. Warp Count controls the number of repeating warp colors. Weft Count controls the number of available weft colors and horizontal sections inside each cell. Grid dimensions: 1–40. Warp and Weft counts: 1–16.
