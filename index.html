Tool Guide & Keyboard Shortcuts

🧵 Warp & Weft

Warp colors define the borders of the cells. Weft colors are used to paint the inner sections of each cell. Warp colors repeat automatically across the columns.

Select a color from the Warp or Weft panel. Use the color picker to customize each yarn color.

🖌 Paint Tool

Unlock painting first, then select a Weft color. Click an empty section to paint it. Click the same color again to remove it. Selecting a different color replaces the previous color.

🔒 Painting Lock

Painting is locked by default to prevent accidental edits. Click the lock button to enable painting. Lock painting again when you finish editing your design.

✋ Hand Tool & Canvas Navigation

Hold the Space key and drag with your mouse to move around the canvas. This temporarily activates the Hand Tool, just like in Adobe Photoshop. Release Space to return to your previous tool.

On mobile devices, swipe directly on the canvas to navigate.

📐 Dimensions & Yarn Structure

Columns and Rows define the size of your design grid. Warp Count controls the number of repeating warp colors. Weft Count controls the number of available weft colors and horizontal sections inside each cell.

Grid dimensions: 1–40 columns and rows. Warp and Weft counts: 1–16.
